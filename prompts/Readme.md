# GenAI Usage Documentation — Team CyED3

**Project:** CED-III-IT2 — Sentiment Analysis on GoEmotions
**Course:** Computación y Estructuras Discretas III (2026-2)
**GenAI Usage Level:** 3 — Collaboration with GenAI

According to the assignment specification, Level 3 requires that students keep a
record of their interactions with GenAI, including the prompts used and their own
authored input, and that they demonstrate the ability to modify, critique and
refine the generated results.

## Document Structure

Each member provides two complementary documents:

1. **`AIGen_Interactions.md`** — a compact table with four columns: date, prompt
   (context + request), summary of the AI output, and the member's own
   adjustments and refinements.
2. **`prompt_logs.txt`** — a verbose, chronological log containing the full
   context provided to the tool, the verbatim prompt, the output summary, the
   manual adjustments, and the file where the refined result was implemented.
