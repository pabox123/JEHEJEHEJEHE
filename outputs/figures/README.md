# Figures

This folder contains plots generated by the notebooks. Figures are derived artifacts: rerunning a notebook may replace them, and their interpretation depends on the dataset used for that run.

## Available figures

The current repository contains the figures from the DistilBERT development run:

- `04_sequence_length_distribution.png` - distribution of tokenized sequence lengths
- `04_transformer_training_curves.png` - training and validation loss and accuracy by epoch
- `04_transformer_confusion_matrix.png` - test-set confusion matrix

The plots were generated by the Transformer notebook and correspond to a balanced 1,000-comment dataset. The available artifacts include training curves and the confusion matrix for the 200-comment test split.
